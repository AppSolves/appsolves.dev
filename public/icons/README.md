# Google Play mark

`google-play.svg` preserves the four prism paths, viewBox, and colors from the official Google Play storefront header at https://play.google.com/store/apps/details?id=dev.appsolves.tag_vault (retrieved 2026-10-08). Only the storefront-specific CSS class was removed. The mark is rendered locally at 16px beside the developer-page link, without a badge or runtime hotlink.
